# 배포 후 브라우저 체크리스트

## 1. 서비스 URL 확인

Render에서 생성된 서비스 URL을 브라우저에 입력합니다.

```text
https://<your-render-service>.onrender.com
```

## 2. 기본 로딩 확인

- [ ] 페이지가 정상적으로 로드됨
- [ ] 브라우저 콘솔에 오류가 없음
- [ ] 캔버스 영역이 보임
- [ ] 페이지 상단 또는 사이드 영역 UI가 정상적으로 표시됨

## 3. 기본 기능 확인

- [ ] 도형 생성 툴이 정상 작동함
- [ ] 직선/다각형/원형 도형이 캔버스에 표시됨
- [ ] 도형 클릭 시 선택 상태가 나타남
- [ ] 선택된 도형에 핸들이 표시됨
- [ ] 이동 드래그가 정상적으로 동작함
- [ ] Shift 키를 누른 상태에서 다중 선택이 가능함
- [ ] 선택 해제가 정상적으로 동작함

## 4. 회전 기능 확인

- [ ] 회전 핸들이 다른 핸들과 구분되어 보임
- [ ] 회전 중 각도가 표시됨
- [ ] 회전 각도를 입력하고 반영되는지 확인
- [ ] 회전 방향과 값이 일관됨

## 5. trim 기능 확인

- [ ] trim 툴 활성화
- [ ] 두 개 이상의 도형이 교차하도록 구성
- [ ] trim 후보가 하이라이트로 표시됨
- [ ] KEEP/CUT 경계가 시각적으로 구분됨
- [ ] 절단 후 남는 경로가 올바르게 유지됨
- [ ] 잘못된 교차는 절단되지 않음

## 6. 텍스트 및 입력 확인

- [ ] 텍스트 입력 UI가 보임
- [ ] 텍스트를 입력하고 반영됨
- [ ] 입력 필드와 도형 툴이 충돌하지 않음
- [ ] 숫자 입력, Delete, Backspace, Enter 동작이 안정적임

## 7. 저장/불러오기 확인

- [ ] 저장 버튼이 동작함
- [ ] 저장 후 파일이 생성됨
- [ ] 불러오기 기능이 정상 복원됨

## 8. 배포 상태 확인

- [ ] Render 대시보드에 `Live` 상태 표시됨
- [ ] 최근 빌드가 성공적으로 완료됨
- [ ] 서비스 로그에 심각한 오류 없음
- [ ] 외부 접속이 가능한 상태임

## 9. 최종 검증 기준

다음 항목이 모두 만족되어야 최종 배포 완료로 간주합니다.

- [ ] 앱이 로드됨
- [ ] 주요 CAD 동작이 동작함
- [ ] 브라우저 콘솔 오류 없음
- [ ] 서버가 정상 실행 중임
- [ ] URL에 접속하면 즉시 사용할 수 있음

## 10. 빠른 점검 명령

배포 후 즉시 확인할 수 있는 최소 체크리스트:

```text
1. Render URL 접속
2. 캔버스 확인
3. 도형 생성
4. 선택/이동
5. 다중 선택
6. 회전
7. trim
8. 저장/불러오기
9. 콘솔 오류 확인
```

## 11. 참고

이 체크리스트는 로컬에서 검증된 기능과 배포 환경에서 확인해야 하는 외부 동작을 함께 점검하기 위해 작성되었습니다.
