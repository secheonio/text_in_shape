# 아키텍처 설계

## 개요

이 프로그램은 문서 템플릿 에디터로, 사용자가 용지와 도형을 선택한 뒤 도형 내부에만 텍스트를 입력하고, `.sit` 포맷으로 저장하여 다시 재사용하는 흐름을 제공합니다.

## 핵심 구성

### 1. UI 레이어

- `EditorApp`: 메인 윈도우와 메뉴/툴바/캔버스 관리
- 용지 선택 및 도형 추가 버튼 제공
- 텍스트 편집 및 속성 설정 UI 제공

### 2. 도메인 모델

- `Paper`: 용지 정보
- `ShapeItem`: 도형의 위치, 크기, 속성, 내부 텍스트
- `TemplateDocument`: 문서 전체 구조를 담는 모델

### 3. 저장 관리

- `TemplateManager`: `.sit` 템플릿 압축 저장 및 불러오기
- `document.json` 안에 구조 정보를 저장

## 동작 흐름

1. 사용자가 용지 크기 선택
2. 도형 선택 또는 이미지 불러오기
3. 도형 선택 후 텍스트 입력
4. 텍스트가 도형 경계 안에 한정되어 표시
5. `.sit` 확장자로 저장/불러오기

## 확장성

- 미래에 텍스트 스타일, 다중 페이지, 이미지 마스크 기능 추가 가능
- `TemplateManager`는 포맷 버전 관리가 쉬운 구조로 설계
- 도형 종류와 속성을 모델로 분리해 기능 추가를 용이하게 구성
